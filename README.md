#  Práctica de Lógica de Programación: Cálculo de Factorial en JavaScript

Este repositorio contiene la solución a un ejercicio práctico enfocado en lógica de programación, validación de datos de entrada y estructuración de 
funciones en **JavaScript**.

---

##  Descripción del Problema
El programa tiene como objetivo principal calcular el **factorial** de un número entero positivo ingresado por el usuario.

### Reglas y Validaciones Implementadas:
1. **Entrada de Datos:** Solicita un número al usuario.
2. **Validación Estricta:** Verifica que el valor ingresado sea un número válido, que sea mayor o igual a `0` y que se trate de un número entero
   (rechazando decimales, letras o valores nulos usando `isNaN` y `Number.isInteger`).
4. **Cálculo Matemático:** Utiliza una estructura de control iterativa (`for`) para multiplicar de forma acumulativa los valores desde `1` hasta el
   número ingresado ($n! = 1 \times 2 \times 3 \times ... \times n$).
6. **Salida de Resultados:** Muestra el resultado final de forma clara a través de la consola del entorno de ejecución.
